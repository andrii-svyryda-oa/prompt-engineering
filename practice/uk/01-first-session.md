# Практичне заняття 1 — Перша сесія Claude Code

**Мова:** українська · [English](../01-first-session.md)

**Час:** 45–60 хвилин  
**Коли:** після лекції 1  
**Працюйте в:** `practice/starter-campusdesk/`

## Мета

Встановити Claude Code (якщо він ще не встановлений), відкрити його в проєкті CampusDesk, дослідити репозиторій (нічого не зламавши), а потім **самостійно** запустити тести й попросити Claude пояснити результат.

## Підготовка

1. Перевірте, чи встановлено Python 3.11+: `python --version`
2. Створіть віртуальне середовище (venv) і встановіть залежності, перебуваючи в `practice/starter-campusdesk`:

```bash
python -m venv .venv
```

Windows: `.venv\Scripts\activate`  
macOS/Linux: `source .venv/bin/activate`

```bash
pip install -e ".[dev]"
pytest
ruff check .
```

3. Встановіть Claude Code за актуальними офіційними інструкціями (приклад для Windows PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

4. Увійдіть у систему, коли з'явиться запит. Вам знадобиться підписка, яка дозволяє використовувати Claude Code.

## Завдання

### 1. Запустіть агента в правильній теці

```bash
cd practice/starter-campusdesk
claude
```

Якщо запустити Claude з кореня курсу, він бачитиме всі лекції та презентації. Це створить неправильний контекст для роботи над застосунком.

### 2. Досліджуйте код без правок

Увімкніть режим **Plan** (натискайте `Shift+Tab`, доки не побачите цей режим на індикаторі) або прямо вкажіть це в промпті:

```text
Не змінюй жодних файлів.
Досліди CampusDesk.
Поясни: що це за продукт, як його запускати, як тестувати 
і де саме додавати нове поле тікета.
Вказуй шляхи до файлів.
```

**Пройдено, якщо:** ви отримали відповідь зі згадкою `app/main.py`, `app/store.py`, `app/models.py`, `pytest` та `uvicorn`. Якщо агент починає редагувати код, натисніть `Esc` і нагадайте йому про заборону змінювати файли.

### 3. Свідомо прикріпіть файл

```text
@docs/product.md
Опиши одним абзацом: для кого цей продукт? Не редагуй жодних файлів.
```

**Пройдено, якщо:** опис відповідає змісту product.md (requester, IT staff, lead).

### 4. Реальний стан справ із термінала

Виконайте в промпті Claude таку команду:

```text
!pytest -q
```

Потім напишіть:

```text
Чи успішно пройшли тести? Процитуй рядок із підсумком. Не змінюй код.
```

**Пройдено, якщо:** Claude цитує реальний вивід pytest, який ви щойно отримали, а не вигадує щось на кшталт «усі тести пройшли успішно».

### 5. Невелике питання на читання коду

```text
Що станеться, якщо я зроблю GET /tickets/9999? Вкажи на обробник.
Досі ніяких правок файлів.
```

**Пройдено, якщо:** агент вказує на обробник 404 помилки в `main.py` (або еквівалентний).

### 6. Команди, які варто спробувати хоча б раз

Введіть `/help` і `/context`. Зробіть знімок екрана або занотуйте:

- чи завантажились якісь файли Memory (ймовірно, ще ні — цим ми займемося на другому занятті)
- що загалом займає місце у вікні агента

## Результат

Коротка нотатка (у форматі markdown у вашій теці з домашніми завданнями, не обов’язково додавати в репозиторій проєкту):

- версія Claude Code (`claude -v`)
- три шляхи до файлів, про які ви дізналися
- що показала команда `/context` у розділі Memory
- одна річ, у якій агент трохи помилився (якщо таке було)

## Можливі проблеми

| Проблема | Що робити |
| --- | --- |
| `claude` not found | Перезапустіть термінал після встановлення; перевірте змінні PATH. |
| Неправильна оболонка на Windows | Команди встановлення для PowerShell і CMD відрізняються, будьте уважні. |
| Тести падають ще до старту | Зверніться до викладача. Не намагайтеся «виправити» це самостійно до практичного 5, хіба що ви впевнені, що проблема у вашому середовищі. |
| Claude редагує README | Ви не були в режимі Plan; за потреби відкотіть зміни (`Esc` `Esc`). |

## Завдання із зірочкою

Відкрийте ще один термінал і запустіть API: `uvicorn app.main:app --reload`. Запитайте Claude (попросивши нічого не редагувати), як створити тікет через HTTP. Спробуйте зробити це за допомогою curl або через UI документації за адресою `/docs`.

# Практичне заняття 8 — Проєктна документація, якою зручно користуватись агенту

**Мова:** українська · [English](../08-project-documentation.md)

**Час:** 50–70 хвилин  
**Коли:** після практичного заняття 7  
**Залежить від:** Assignee (або те, що ви реалізували) справді існує

## Мета

Зробіть документацію **короткою, структурованою та легкою для пошуку**, щоб у наступній сесії агенту не довелося виконувати explore по 20 файлах. На практиці перевірте компроміс із лекції 4: робити import файлу чи лише вказувати шлях до нього.

## Завдання

### 1. Аудит поточної документації

Прочитайте `docs/product.md`, `docs/architecture.md`, `README.md`, `CLAUDE.md`.

Позначте кожен як:

- **застарілий** (не відповідає коду)
- **занадто великий для команди import**
- **відсутній заголовок**, за яким агент міг би його знайти

### 2. Виправте застарілість

Разом із Claude, спершу в режимі Plan:

```text
Порівняй docs/architecture.md та docs/product.md з поточним API.
Виведи лише розбіжності. Не переписуй усе з нуля.
```

Після цього застосуйте **мінімальний** патч. Без зайвих маркетингових описів.

### 3. Додайте сторінку HTTP-прикладів

Створіть `docs/http-examples.md` з командами `curl` (або httpx), які можна копіювати, для:

- health
- list / filter, якщо практика 5 існує
- створення тікета з assignee і без
- patch assignee на значення і на null

Вкладіться приблизно у 80 рядків.

### 4. Правила в CLAUDE.md

Оберіть **одне**:

**A.** Import `docs/http-examples.md` (лише якщо файл лишився крихітним)  
**B.** Не робити import; додайте: «HTTP examples: `docs/http-examples.md` — читайте, коли змінюєте API.»

У звіті до домашки напишіть два речення: що саме ви обрали та як це вплине на споживання токенів.

### 5. Skill для документації

`.claude/skills/sync-docs/SKILL.md`:

- Якщо поведінка API змінюється, онови architecture + http-examples + статус специфікації
- Не дублюй специфікацію в product.md
- Використовуй product.md для опису користувачів та ролей, а не для JSON-схем

Викличте `/sync-docs` після фіктивного запитання: «Чи задокументували ми очищення assignee через null?»

**Залік:** Skill або підтверджує, що приклад є, або самостійно його додає.

### 6. Експеримент із вкладеним CLAUDE.md (додатково)

Додайте `docs/CLAUDE.md` з одним рядком: «Ці файли для людей і агентів; надавайте перевагу заголовкам, а не суцільному тексту.» Запустіть Claude з `app/` і з кореня репозиторію і подивіться (лекція 2), коли підтягуються вкладені файли CLAUDE.md. Занотуйте це.

## Результат

- Оновлена документація + `http-examples.md`
- Skill `/sync-docs`
- Ваше рішення щодо використання import чи просто згадки файлу
- Кількість слів у `docs/architecture.md` до і після (документ не повинен роздутися)

## Додатково

Додайте в README таблицю «Карта документації» (шлях → призначення). Вона має поміститися на один екран.
